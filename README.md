# Фильтр частиц

## Описание

Реализация одномерного фильтра частиц на языке C.
Программа моделирует движение объекта по прямой и оценивает его положение
по зашумлённым показаниям датчика.

## Структура проекта

```
particle_filter/program/
|-- particle.h     — объявления структуры и функций
|-- particle.c     — реализация алгоритма
|-- main.c         — тестирование и получение результатов
|-- visual.py      — визуализация результатов
|-- Makefile       — сборка проекта
```


## Сборка и запуск

### Требования
- GCC
- Make
- Python 3 с библиотеками `pandas` и `matplotlib`

### Установка библиотек Python
```bash
pip install pandas matplotlib
```

### Команды

```bash
# только сборка
make

# сборка и запуск
make run

# сборка, запуск и визуализация
make visual

# удалить собранные файлы и результаты
make clean
```
